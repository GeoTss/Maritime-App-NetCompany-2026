# Ops console (apps/web): surface brief

Scope: the whole ops console: map, inbox, approvals, evaluation, the assistant dock. Mode: Operate. Audience: the bunker-to-berth operator, plus a jury watching a six-minute demo. Constraints: PRODUCT.md (cited facts, approve-first, honesty tags, offline, no CDN).

## Direction contract

THESIS: Every state on the desk flies as a code flag, colour and pattern together, so nothing has to be read twice. It refuses the category's dark-dashboard-with-neon-accents arrangement.

OWN-WORLD: The International Code of Signals' five pigments on a dark ground (#0e1114 ground, #151a1f panels). Light signal blue #6f9bff is used to act and for the recommended option, with true signal blue #1f4fb0 on the one solid primary. Yellow #ffc72c means needs you, and red means blocked or reject. There is no green. ICS flag glyphs (K needs you, V assistance, U danger, C yes, N no) sit beside every status word. Type is Atkinson Hyperlegible Next, with its Mono for identifiers only.

STORY: The operator sees what needs them and why, reads every number's source, and approves knowing exactly what happens.

FIRST VIEWPORT: A 48 px top bar holds the wordmark, the four screen tabs with flag count badges, the source modes, the clock and ⌘K. Below it sit a Needs-you column on the left, the map in the centre with the cited plan drawn, and the assistant on the right. The primary action is "Review and decide" in solid signal blue.

FORM: grounded candidate 4 of 7 (International Code of Signals flags); seed:2a31fdc12c02713d. User modifications pinned 2026-11-17: "make it dark themed and without the extra tabs" (dark ground; screen tabs only, no open-subject tabs).
